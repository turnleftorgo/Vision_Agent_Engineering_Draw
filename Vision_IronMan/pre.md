# Qwen VL 检验截图字段识别需求

## 目标

每当检验表格新增一张可用的精修截图（`crop_refined`），或用户保存人工重新裁剪的截图时，使用配置的 Qwen VL 模型识别截图中有明确证据的检验字段，并将结果回写到该截图所属的表格行。

## 模型

- 默认模型标识：`Qwen3.6-35B-A3B-MLX-8bit`
- 推理服务：复用项目现有 OpenAI-compatible 本地 VLM endpoint（默认 `http://127.0.0.1:8001/v1`），允许通过环境变量覆盖。

## 字段规则

- 只识别截图里可见且能确认属于该记录的字段；缺失、不可读或有歧义的值必须留空，禁止猜测。
- 图片识别结果只写入对应 `record_id` 的空白字段，不覆盖已有值，以保护用户编辑。
- `No.` 由程序生成；图纸级 Project、Revision、Author、Date 和程序已知 Page 等上下文不要求模型从单条裁剪图推断。
- 可识别的行字段包括 FAI、SPC、Description、Nominal、USL、LSL、100%、DC、Points；Module 仅在截图证据清晰或后端已有可靠上下文时填写。
- `crop_refined` 为初始识别图；用户保存的人工裁剪图优先级更高。
- 提示词明确 DC 等行字段可选，不要求模型返回每个字段。模型 JSON 中某个字段（例如 DC）缺键、未出现或不可读时，仅将该字段视为未发现；其余有效字段照常校验与回写，不因单个字段缺失而丢弃整份识别结果。

## 触发、幂等和并发

- 初次精修截图落盘并创建表格记录后触发一次。
- 人工裁剪保存并成为有效截图后触发一次；拖动预览但未保存不触发。
- 页面重载、轮询和同一截图的重复事件不能重复调用模型。
- 以记录 ID 和截图内容版本/哈希识别任务；旧截图推理晚于新截图完成时，旧结果不得覆盖新版本状态。
- 模型调用异步执行，表格应可继续使用，并呈现等待、处理中、完成、需复核或失败状态。
- 验证模型 JSON、字段白名单和返回记录 ID；保存结构化结果、模型/提示版本、截图版本和错误信息以便追踪。

## 验收标准

- 新增精修图和已保存人工裁剪均能分别触发识别。
- 同图重复事件不重复推理；未保存的拖框不触发。
- 有效识别值只填入本行空单元格；空值不清除内容，人工值不被覆盖。
- 图片缺少字段或模型无法可靠判断时对应单元格保持空白，并提供可复核状态。
- 更换截图期间产生的过期模型结果不会回写。

## 第 1 页 module 元数据识别

- 第 1 页的每次 Qwen 27B module 识别调用追加纯文字提示词，检查当前 module 图像中可见的 Project、Revision、Author、Date。
- 不传入整页图或标题栏额外图片；当前 module 图像仍是原识别调用既有输入。
- Project 从 `Metric / Title` 表格内部最底下一行识别。
- Revision、Author、Date 必须从修订历史中同一条最新有效记录的 `REV`、`AUTHOR`、`DATE` 列读取；不得从图纸编号或不同记录行拼接。
- module 输出元数据候选，run 级汇总一致、有证据的候选后填顶部四项；缺失/歧义留空，冲突不写入。
- 其他页不执行此提示词；页面级字段不写入某一条检验行的专属字段。

## 精修与表格 AI 处理可视状态

- Crop 2 精修期间，在原图上以蓝紫色流动框显示当前轮次的裁剪区域；每次方向指令产生新区域后，框随实际 `crop_after` 更新，结束时消失。
- 截图进入表格并等待或正在由 Qwen3.6-35B-A3B-MLX-8bit 识别时，整行显示蓝紫色流动边框；识别结束后取消动画。
- 新记录的 Description 初始为空，Stage 2 模糊识别结果不得填入或覆盖该列；自动识别内容仅来自截图字段提取模型，人工编辑仍可保留。
- SPC 截图缩略图下不显示 AI 状态、复核或人工修改小标签。

## 截图字段 JSON 输出约束

- 截图识别请求必须同时在提示词和 OpenAI-compatible API 参数中要求 JSON；API 使用 `response_format: {"type":"json_object"}`，不能只依赖自然语言约束。
- 模型返回后仍执行本地 JSON 解析、字段白名单与状态校验；每次结果记录新的 JSON mode 识别版本。

## Qwen 35B 独立诊断脚本

- 在 `tests/diagnose_qwen35b_extraction.py` 提供可单独运行的诊断脚本，默认从 SQLite 只读定位最近一次 35B 失败记录的截图，也可手动指定图片；复现当前生产 JSON 请求并对照无 JSON mode、关闭 thinking 的请求。
- 每轮保存脱敏请求参数、HTTP 状态与响应头、完整响应原文、模型返回内容、finish_reason、token 用量、解析结果/异常、耗时和图片 SHA-256；禁止将图片 base64 写入日志。
- 诊断输出采用独立时间戳目录，不写生产 SQLite，不回填表格。
